# WiFi Guard 2.0

تطبيق أندرويد لمراقبة شبكة الواي فاي والتحكم بالراوتر، محمي برمز سري.
Java صافي بدون أي مكتبة خارجية — الحد الأدنى أندرويد 8 (API 26).

## الميزات

**المراقبة (من النسخة 1.0)**
- تحليل الشبكة المتصلة: نوع التشفير، درجة تقريبية، الإشارة، IP، البوابة، DNS.
- الشبكات القريبة مع تمييز ضعيفة التشفير.
- اكتشاف الأجهزة المتجاوبة على الشبكة المحلية.
- تقرير قابل للمشاركة وسجل محلي اختياري.

**الجديد في 2.0**
- **رمز سري إجباري** (4–8 أرقام) عند فتح التطبيق، مع بصمة اختيارية وقفل تلقائي وتأخير متصاعد بعد المحاولات الخاطئة.
- **خزنة راوترات**: تحفظ العنوان واسم المستخدم وكلمة المرور مشفّرة بـ AES-256-GCM بمفتاح داخل Android Keystore.
- **لوحة الراوتر داخل التطبيق** مع دخول تلقائي، وتعمل مع أي راوتر له صفحة ويب (TP-Link / Huawei / ZTE / Tenda / غيرها).
- **عنوان محلي وعنوان عن بعد** لكل راوتر (Remote Management / DDNS / VPN).
- كشف تلقائي لماركة الراوتر ودليل لمكان تحديد السرعة وحظر المواقع في كل ماركة.
- **تحكم مباشر تجريبي لراوترات Tenda (سلسلة AC)**: قائمة الأجهزة من الراوتر، تحديد سرعة جهاز، حظر مواقع، جدولة الإنترنت، إعادة تشغيل، تمييز الأجهزة الجديدة وتسميتها.
- نسخة احتياطية مشفّرة بكلمة مرور لنقل الراوترات لهاتف آخر.
- منع لقطات الشاشة داخل التطبيق.

**الجديد في 2.1**
- بطاقة لكل راوتر: ملوّنة إذا الراوتر يرد، وخافتة إذا طافي أو بعيد.
- زر «تحكم من بعيد» بكل بطاقة، والتطبيق يختار الاتصال المحلي أو البعيد تلقائياً.
- فحص لراوترات Tenda يقرأ عنوان WAN ويكلك هل التحكم من بعيد ممكن (يكشف CGNAT).
- التعرف التلقائي على راوتر الشبكة الحالية واقتراح حفظه.
- شاشة Tenda بسيطة: الأجهزة المتصلة وأزرار سريعة، و«تقرير تشخيص» يساعد بضبط الموديلات المختلفة.
- لا يُرسل الدخول التلقائي لراوتر على شبكة غير شبكة البيت المحفوظة.

**الجديد في 2.2**
- تبويب «الأجهزة» يقرأ القائمة من الراوتر: الاسم، النوع، الاستهلاك، وآخر ظهور.
- شاشة لكل جهاز: تغيير الاسم بالراوتر نفسه، قطع النت، وقت السماح (وقت النوم)، حظر المواقع الإباحية، وتحديد السرعة.
- كل أمر يُقرأ من الراوتر بعد إرساله حتى نتأكد أنه انحفظ.
- «حماية كل البيت» بـ DNS العائلي من Cloudflare (1.1.1.3 و 1.0.0.3).
- تنبيه عند اتصال جهاز جديد، وويدجت للشاشة الرئيسية، ومشاركة الواي فاي بـ QR.
- تقرير تشخيص لأي راوتر، لإضافة ماركات جديدة.
- رابط تحميل ثابت: https://github.com/tara44x-code/WiFiGuard-pro/releases/latest/download/WiFiGuard.apk

## مفتاح التوقيع

حتى يتثبت كل تحديث فوق القديم بدون ما تنحذف البيانات، أضف سرّين بالمستودع
(Settings ← Secrets and variables ← Actions): `SIGNING_KEY` (المفتاح بصيغة base64) و `SIGNING_PASSWORD`.
بدونهم كل بناء ينوقّع بمفتاح جديد.

## الحدود (بصراحة)

- لا يوجد بروتوكول موحد لكل الراوترات. تحديد السرعة وحظر المواقع ينفَّذان من لوحة الراوتر نفسها، ويتوفران فقط إذا كان الراوتر يدعمهما.
- التحكم المباشر متوفر حالياً لـ Tenda فقط، ومكتوب اعتماداً على مشاريع مفتوحة المصدر لنفس الواجهة **ولم يُختبر على جهاز حقيقي**. بقية الماركات تعمل بالوضع العام.
- التحكم من بعيد يتطلب تفعيله في الراوتر أولاً. فتح لوحة الإدارة على الإنترنت بكلمة مرور ضعيفة خطر؛ الأفضل VPN أو https.
- المشروع لم يُبنَ بعد على Android SDK حقيقي؛ أول بناء يكون عبر GitHub Actions أو Android Studio.

## بناء الـ APK

**عبر GitHub (بدون حاسوب):** ارفع المشروع إلى مستودع، ثم افتح تبويب **Actions** ← **Build APK** ← آخر تشغيل ← نزّل `WiFiGuard-debug-apk` من قسم Artifacts.

**عبر Android Studio:** افتح المجلد ثم Run. أو من الطرفية:

```
./gradlew assembleDebug
```

ملاحظة: نسخة debug موقّعة بمفتاح مختلف عن نسختك القديمة، فاحذف التطبيق القديم قبل التثبيت.

## هيكل الكود

| الملف | الوظيفة |
|---|---|
| `MainActivity` | التبويبات الخمسة |
| `LockActivity` / `BaseActivity` | الرمز السري وقفل الجلسة |
| `Vault` | تجزئة الرمز، التشفير، تخزين الراوترات، النسخ الاحتياطي |
| `RouterActivity` | لوحة الراوتر مع الدخول التلقائي |
| `RouterDetect` | كشف الماركة والدليل |
| `TendaDriver` / `NativeControlActivity` | التحكم المباشر التجريبي |
| `NetworkEngine` / `LocalDiscovery` | تحليل الشبكة واكتشاف الأجهزة |

## إضافة ماركة جديدة للتحكم المباشر

اكتب كلاس مشابه لـ `TendaDriver` (دخول، قائمة الأجهزة، تحديد السرعة، الرقابة) واربطه في `NativeControlActivity`. يلزم راوتر حقيقي من نفس الموديل للاختبار.

## الخصوصية

لا يتصل التطبيق بأي خادم. كلمات المرور تُرسل للراوتر نفسه فقط. استعمل التطبيق مع الراوترات التي تملكها أو تديرها.
